How updates work

An update replaces the app. Your household (papers, settings, the database) lives in a folder of its own and is not touched.

  1. You hear about it. Once a day {{ brand }} looks for a newer version (the switch above turns this off). A new version shows on Today and in the Inbox. Nothing installs without you.
  2. You install it. Download the new installer from the {{ brand }} website and run it, the same way you installed it the first time. On Windows the installer closes the {{ brand }} that is running, then replaces the app files; it keeps using your household folder and does not ask for it again. On a Mac, quit {{ brand }}, open the new download and drag it to Applications, replacing the old one. {% if upd.newer and not upd.site and not upd.container %}This copy can also update itself with Update to {{ upd.newer }} above. It checks the release signature, keeps a copy of the old app files, and starts {{ brand }} again by itself.{% endif %}
  3. The first start brings the records up to date. Before any change to the database, a copy of it is saved. If that step cannot finish, {{ brand }} does not start and your records stay as they were; the copy is kept in the backups folder.

Never replaced or removed by an update: your papers (archive), the inbox, your records in the database (the first start only adds what the new version needs), settings and PINs, reports and briefs, and anything you added yourself. Old app files that a new version no longer needs are moved aside, not deleted.

To be extra safe, back up first: Settings > Data > Backups > Back up now.
